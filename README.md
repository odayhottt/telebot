# بوت تيليجرام - نسخة كاملة (Multipost + جدولة + ترحيب/وداع + فلتر انضمام)

## الملفات
- `bot.py` — نقطة التشغيل الرئيسية وكل الأوامر والأزرار
- `database.py` — قاعدة بيانات SQLite (قنوات، إعدادات، منشورات مجدولة...)
- `texts.py` — نصوص الواجهة بالعربي والإنجليزي
- `keyboards.py` — كل لوحات الأزرار Inline
- `requirements.txt` — المكتبات المطلوبة

## المميزات المتوفرة الآن
| الميزة | كيف تستخدمها |
|---|---|
| 🗂 تسجيل القنوات | أضف البوت كمشرف في قناتك، أو أرسل أي منشور فيها |
| 📚 نشر متعدد (Multipost) | من القائمة الرئيسية → نشر متعدد → اكتب النص → اختر القنوات |
| 🕒 منشور مجدول متكرر | من القائمة → منشور مجدول → نص → قنوات → كل دقيقة/ساعة/يوم |
| 📲 ترحيب أعضاء جدد | داخل المجموعة أرسل `/welcome` (يتطلب أن تكون مشرفاً) |
| 🏃 وداع الأعضاء | داخل المجموعة أرسل `/goodbye` |
| 🛡 فلتر انضمام (Captcha) | داخل المجموعة أرسل `/joinfilter` — يطلب من كل عضو جديد الضغط على زر خلال دقيقة، وإلا يُطرد تلقائياً |
| 🖥 سجل الأحداث | من القائمة الرئيسية → سجل الأحداث |
| 🌐 اللغة | من القائمة الرئيسية → اللغة (عربي/إنجليزي) |
| 📖 الدليل و🔧 الدعم | أزرار ثابتة في القائمة الرئيسية |

## صلاحيات مهمة يجب منحها للبوت
- في **القنوات**: مشرف (Admin) بصلاحية النشر
- في **المجموعات**: مشرف بصلاحية "حظر/تقييد الأعضاء" (Restrict members) حتى يعمل فلتر الانضمام، وحذف الرسائل إن أردت لاحقاً

## 1. الحصول على توكن البوت
1. افتح [@BotFather](https://t.me/BotFather) في تيليجرام
2. أرسل `/newbot` واتبع الخطوات
3. احتفظ بالتوكن سرياً (لا تضعه داخل الكود مباشرة عند الرفع لأي مكان عام)

## 2. النشر المجاني على Render (Web Service)
Render لا يوفر Background Worker مجاناً، لذلك هذا الكود يشغّل سيرفر HTTP
صغير بجانب البوت فقط ليبقى النوع "Web Service" يعمل ضمن الخطة المجانية.

الخطوات:
1. أنشئ حساب على [render.com](https://render.com) (تسجيل دخول بـ GitHub متاح من الجوال)
2. ارفع هذا المجلد كاملاً إلى مستودع (repository) جديد في GitHub
3. في Render: **New → Web Service** → اختر المستودع
4. **Build Command:** `pip install -r requirements.txt`
5. **Start Command:** `python bot.py`
6. في **Environment → Environment Variables** أضف: `BOT_TOKEN` = توكن بوتك
   (لا تضف قيمة لـ `PORT` — Render يوفرها تلقائياً)
7. احفظ ونفّذ Deploy

بعد نجاح النشر، افتح بوتك في تيليجرام وأرسل `/start`.

## 3. التشغيل محلياً (اختياري، Termux مثلاً)
```bash
pip install -r requirements.txt
export BOT_TOKEN="ضع_التوكن_هنا"
export PORT=8080
python bot.py
```

## 4. ملاحظات مهمة
- قاعدة البيانات SQLite (`bot_data.db`) تُنشأ تلقائياً بجانب الكود.
  على Render (الخطة المجانية) القرص غير دائم، فقد يُعاد ضبط القاعدة عند
  إعادة تشغيل الخدمة. للاستخدام الجاد لاحقاً، يفضّل الانتقال لقاعدة بيانات
  خارجية دائمة (مثل PostgreSQL المجاني على Render نفسه).
- ميزات مثل **Auto-complete** (إضافة أزرار تلقائياً لأي منشور تكتبه مباشرة
  في القناة) و **Subscription** (خطط اشتراك مدفوعة) لم تُضف بعد لأنها
  تحتاج تصميم إضافي — أخبرني إذا تحتاجها وأبنيها لك.
